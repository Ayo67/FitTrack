# FitTrack

A Flutter project designed to help users track their fitness journey by integrating Fitbit data and providing real-time health statistics and visualizations.

## Overview

This Flutter application allows users to sync their Fitbit wearable data and track metrics such as heart rate, steps, calories burned, and sleep. The app presents these statistics through interactive visualizations, helping users make data-driven decisions about their health and fitness. Firebase is used for secure data storage, and the app is built for scalability to support future enhancements.

## Getting Started

To get started with the project, follow the steps below to set up your development environment and run the app locally.

### Prerequisites

Before you begin, ensure that you have the following installed:

- **Flutter SDK**: Download and install Flutter from the official [Flutter website](https://flutter.dev/docs/get-started/install).
- **Android Studio**: To run the app on an Android emulator or a physical device.
- **Firebase Account**: Set up Firebase to use authentication, Firestore database, and backend features.

### Installation

Follow the steps below to set up the project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ayo67/fittrack.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd fittrack
   ```

3. **Install Flutter dependencies:**  
   Run the following command to install the necessary dependencies:
   ```bash
   flutter pub get
   ```

4. **Set up Firebase:**  
   Follow the [Firebase setup guide](https://firebase.google.com/docs/flutter/setup) to configure Firebase for your project.

5. **Run the app:**  
   Use the following command to run the app on an emulator or connected device:
   ```bash
   flutter run
   ```

## Features

- Sync Fitbit data for real-time health tracking.
- Visualize metrics such as heart rate, steps, calories burned, and sleep patterns.
- Secure data storage using Firebase.
- Scalable architecture for future enhancements.
